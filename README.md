Weather Diary / Дневник погоды

Автор
[Регина Байдрахманова]

Описание
Графическое приложение на Python (Tkinter) для ведения дневника погоды. Позволяет добавлять записи с датой, температурой, описанием и наличием осадков, фильтровать их по дате и температуре, а также сохранять/загружать данные в формате JSON.

Как запустить
1. Убедитесь, что установлен **Python 3.8+**.
2. `tkinter` входит в стандартную библиотеку Python. Для Linux может потребоваться установка:  
   `sudo apt install python3-tk` (Debian/Ubuntu) или `sudo dnf install python3-tkinter` (Fedora).
3. Запустите приложение:
   ```bash
   python main.py
